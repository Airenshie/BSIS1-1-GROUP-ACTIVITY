Questions About Your HTML Page

1. What is the HTML source file?

It contains the code used to create a web page.

2. What does the web browser do with the HTML file?

It reads the HTML code and displays the web page.

3. Which tool did you use to create or edit the file?

Part C: Classify the Language or Tool

Item Classification
HTML Markup Language
JavaScript Programming Language
Assembly Language Low-Level Programming Language
Python Programming Language
Visual Studio Code Code Editor
Chrome or Firefox Web Browser

Discussion

HTML describes the structure and content of a web page. JavaScript makes a web page interactive and allows it to perform functions, such as responding when a user submits a form. A web browser displays a web page, while an IDE provides tools for writing and editing code.

Part D: Open-Source or Proprietary Software

Software Classification
LibreOffice Open-Source
GIMP Open-Source
VLC Media Player Open-Source
Mozilla Firefox Open-Source
Microsoft Windows Proprietary
Microsoft Word Proprietary
Adobe Photoshop Proprietary

1. Open-Source: LibreOffice

Advantage: It is free to use, and users can modify its source code.

Disadvantage: Some files may look different when opened in other office software.

2. Proprietary: Microsoft Word

Advantage: It can open and work with many document file formats.

Disadvantage: A paid license may be required, which can be expensive.

3. What Should Users Consider?

Users should consider the cost, security, compatibility, and license to choose software that best fits their needs.

Part E: Recommendation Challenge

We recommend Apache OpenOffice for the college computer laboratory because it is free to use. It can help students make documents, spreadsheets, and presentations for their schoolwork. It can also help the school save money because there is no need to pay for the software. However, the school should check if its files can open properly in other office programs. The school should also make sure that the software is safe and updated. Lastly, it should check if help and support are available when students have problems using the software.
